# 404號房・序幕、篇章與尾聲

本次增補日期：2026-10-29。適用單人、第一人稱3D探索與2D敘事版。完整世界觀以BRIEF.md為準；保留六關、十二機關與三結局的既有判定。

## 2D前導動畫

從「開始調查」進入，六幕預設約57秒自動播放。以現有場景圖片、HTML文字與CSS動畫製作；不依賴影片服務或後台。圖像慢速平移，配合來電波紋、鏡面字跡浮現、監控掃描線與郵件行文動畫。必要劇情皆有文字，無須聽音辨認。

| 幕 | 時間與畫面 | 敘事用途 | 預設秒數 |
| --- | --- | --- | --- |
| 1 | 1998年・客房與來電波紋 | 林澄獨自入住，隔天清晨致電「房間裡還有一個人」 | 8.5 |
| 2 | 當日清晨・浴室與鏡面字跡 | 人員開門發現空房，鏡內留下「我還在這裡」 | 8.5 |
| 3 | 當晚・監控掃描線 | 像林澄的人早已離館，404卻再次來電 | 10 |
| 4 | 封閉後・四樓走廊與03:17時鐘 | 四樓移除一般停靠，歷年失蹤與反覆電話留下疑問 | 9.5 |
| 5 | 現在・檔案背景與匿名郵件 | 交代玩家獨自調查的動機，以及三項警告 | 11.5 |
| 6 | 02:58・櫃檯與單人登記卡意象 | 玩家抵達，第一個可操作目標是查看住宿登記簿 | 9 |

操作：上一幕、下一幕、暫停／自動播放、略過；空白鍵或Esc切換暫停，左右方向鍵翻頁。動畫中的Tab焦點留在播放控制內。系統或遊戲設定減少動態時停用動畫，預設手動閱讀；仍可自行開啟自動翻頁。

首頁「重看序幕」與筆記同名按鈕可以重看。重看不更動機關、證據、物品或人數；關閉後返回原頁／筆記。新局播完或略過後仍須親自互動住宿簿，不能靠動畫開啟電梯。繼續舊局直接還原進度，不強制重播。

序幕刻意不揭露ROOM-404來源、候補核定機制與真結局處置，留待關卡證據說明。寄件者維持未知；不將研究實驗寫成確定的異常起因。

## 關卡間的篇章

每次進入場景時，在暫停面板呈現該地點的短篇章，把前一段的發現銜接到下一段調查。返回舊場景仍可閱讀，但不增加存檔欄位或重設謎題。

1. 櫃檯：邀請者未出現，先確認登記。
2. 電梯：被封閉的四樓與多出來的乘客。
3. 走廊：抵達案發現場，開啟404。
4. 客房：不同年份房客留下相同警告。
5. 浴室：門外安靜，鏡中細節仍有異常。
6. 監控室：重建過去，再辨認超前訊號。
7. 檔案室：理解旅館如何認定房客。
8. 服務走道：最後確認前仍可補齊證據。
9. 終局櫃檯：對方只問幾位離開，把調查推向最後決定。

## 三種結局的完整尾聲

每種結局保留既有3D離館演出，再顯示2D影像、狀態摘要和三段敘事。玩家可以閱讀「案件解讀」把六關線索串起來，也可把三段文字用2D動畫重看。尾聲及重看不會再次核定退房。返回退房前、重新調查、返回首頁保留。

| 結局 | 發生的事 | 選擇造成的後果 | 尚未解決 |
| --- | --- | --- | --- |
| 尚未結案・1人 | 玩家一人離館，擬態仍留在404 | 候補未核定，但原始入住程序沒有撤銷 | 房間仍可能等待下一位；歷代房客去向未知 |
| 第二位房客・2人 | 櫃檯正式核定候補，兩個輪廓走出大門 | 擬態取得可離館身分，異常擴散 | 原始登記仍保留；不是門外一句回答就自動放它出去 |
| 404 NOT FOUND・撤銷 | 印章蓋在原始頁，無效房號與候補一併撤銷 | 旅館異常層消退，露出廢棄建築；本輪程序終止 | 不宣稱失蹤者復活、所有異常永遠消失或寄件者已揭曉 |

「案件解讀」在完成來源分析後的結局頁可展開；不是探索中的直接謎底提示。

## 逐步指引

左下角固定顯示「現在任務／具體操作／接著去哪裡」，隨既有存檔狀態更新。H或右上「下一步」開完整指引；筆記、暫停與解題完成訊息也附上當前行動。所有解謎面板另有「這一步要做什麼」，保留原來三階提示按鈕，避免一開始直接顯示答案。

| 場景 | 任務推進 |
| --- | --- |
| 櫃檯 | 讀住宿簿 → 前方電梯 |
| 電梯 | 維修路線 → 計數異常 → 前方開門出口 |
| 四樓 | 靠近404按E → 步行進房 |
| 客房 | 比對照片 → 門外回應／沉默 → 浴室；床邊變化可選看 |
| 浴室 | 五處不同 → 照片校準／門禁 → 鏡後通道 |
| 監控 | 排序事件 → 歷年對照 → 斷開超前通道 → 檔案室 |
| 檔案 | 拼合報告／核對 → 來源分析；解鎖抽屜後明確另取印章 → 服務走道 |
| 服務走道 | 向前到櫃檯；可轉身回檔案室 |
| 退房 | 預覽人數／查看原始頁；缺印章可回取 → 確認後尾聲 |

方向以場景首次進入時為基準；實際標牌與E互動提示為準。返回途中可轉頭辨認標示。指引由既有旗標推導，未修改存檔版本，也不代替互動、碰撞或門禁條件。
