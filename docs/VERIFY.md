## 2. 驗收方法

優先級：P0為無法移動、卡關、錯誤結局、遺失進度等阻擋問題；P1為必要體驗及規則；P2為不阻擋流程的呈現問題。

測試環境須記錄版本或提交識別、日期、作業系統、瀏覽器完整版本、解析度、縮放比例、硬體、畫質與存檔來源。執行數值移動測試時另記錄更新頻率及量測方式。

每次結果使用以下格式，不能只填「看起來正常」：

| 欄位 | 必填內容 |
|---|---|
| 案例ID／版本／執行者／時間 | 能對回同一版可執行成品 |
| 前置條件 | 關卡、機關旗標、出生位置、物品與操作模式 |
| 步驟與實際結果 | 重現操作、預期與實際差異 |
| 判定 | 通過／失敗／阻擋／未執行；附阻擋原因 |
| 證據 | 畫面錄影、截圖、位置記錄、必要的狀態快照或錯誤紀錄 |

工程模式可以提供座標、碰撞框、互動射線與旗標，但正式遊戲不顯示內部代碼。人工遊玩必須包含一輪不開除錯功能的首次體驗。
