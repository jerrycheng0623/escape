## 執行環境與規則

每次填寫版號、日期、OS、瀏覽器完整版本、硬體、視窗、縮放、存檔來源及執行者。結果分為未執行／通過／失敗／阻擋。錯誤保留重現方式與修正後重測，禁止把預期當實際。工程層驗證不代替正常遊玩。

證據保存在測試證據資料夾，檔名含案例ID。桌面測1280×720與1920×1080，縮放100%及125%；手機橫向操作另依MOB案例驗證；觸控模擬與實體手機分開記錄。
