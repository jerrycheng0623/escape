## 製作方式與設計鎖定

使用者已接受：依生成圖片參考製作真正GLB模型及動畫，不宣稱以單張圖片自動重建精細模型。圖片使用內建Image Gen；3D採人工定義幾何、材質、節點及動畫，輸出可重用GLB。介面、文件及謎底文字保持HTML可閱讀，不烘焙成不可修改的網頁截圖。

整體方向：1990年代永安旅館，褪色奶白牆、暗綠壁裙、磨損胡桃木、黃銅、米色床單、暖鎢絲與冷螢幕。恐怖依靠空位、重影、過期紀錄與延遲，沒有血腥或怪物追逐。3D模型採有細節的低多邊形材質風格，以同一圖片方向製作；不冒稱電影級掃描模型。

模型通用：Y軸向上，1單位=1公尺；至少可讀取position、normal與材質，動畫時間單位為秒。可活動部分有固定節點名；GLB可獨立載入檢查，不只在JS中臨時拼出無檔模型。

## 動畫事件規格

| 事件 | 觸發／長度目標 | 完成後狀態 |
|---|---|---|
| 電梯開門 | 機關02完成／1.4秒 | 門片保持開，出口碰撞解除 |
| 雙枕頭 | 機關04完成／1秒 | 第二枕頭持續可見，回訪不重播 |
| 鏡後通道 | 機關06完成／1.4秒 | 牆板保持開；可雙向通行 |
| 印章抽屜 | 機關09完成／0.9秒 | 開啟後可主動取印章 |
| 員工抬頭 | 錯誤退房確認／2秒 | 進入對應結局分鏡 |
| 擬態步行 | 鏡中／監控演出／循環2秒 | 不移動玩家，不產生碰撞 |
| 印章蓋下 | 真結局確認／0.8秒 | 先保存檢查點，後撤銷，僅一次 |

暫停時動畫停在當前時間，降低刺激模式可縮短或略過非必要轉場，但終態、證據與門禁相同。讀檔依旗標套用終態，不重複開門音效或發道具。
