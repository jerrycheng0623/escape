## 1. 本次計畫的依據與界線

使用者已確認第一人稱3D探索，搭配2D劇情、文件與解謎介面；人物僅支援走路、轉頭與互動。畫面中可用2D剪影、貼圖與預製監控片段營造恐怖，但實際探索必須具備3D位置、自由轉頭、碰撞及距離判定。

已存在七份劇情設計文件；目前未有遊戲程式、引擎或資產。此文件規劃後續製作，不代表已開始建置網站或遊戲。本輪僅新增兩份規格文件並同步舊設計。

## 2. 呈現方式

| 層次 | 內容 | 互動規則 |
|---|---|---|
| 3D探索 | 櫃檯、電梯、走廊、404、浴室、監控室、檔案室與服務走道 | 玩家實際走到物件前、轉頭觀察、按E互動 |
| 2D劇情 | 匿名信、對白分鏡、字幕、結局、首頁 | 可閱讀、適當跳過；必要狀態完整結算 |
| 2D解謎 | 樓層盤、照片歸檔、鏡面快照比對、疊影、監控、報告與退房 | 由3D物件開啟面板；暫停走路與視角；關閉回原站位 |
| 2D常駐介面 | 準星、互動提示、物品、筆記、設定 | 提示繁體中文，不提前標記正解 |
| 特殊影像 | 倒影、額外人影、歷史與未來監控 | 允許採預製2D片段／場景內影像平面；不可讓虛構人影改變現實碰撞或真實計數 |

第三關的鏡中找異常使用刻意固定的實景快照與鏡面素材，避免自由視角造成答案漂移；進出浴室、走近鏡子及通往下一區仍是3D行走。

## 3. 人物與操作規格

### 3.1 操作

| 操作 | 預設輸入 |
|---|---|
| 前後左右走路 | WASD |
| 轉頭 | 滑鼠；探索模式另支援方向鍵轉頭 |
| 查看／使用面前物件 | E |
| 物品／調查筆記 | I／J |
| 關閉面板／暫停 | Esc；瀏覽器釋放游標時也須安全暫停 |
| 恢復探索 | 點擊「繼續探索」，再取得游標鎖定 |

不加入跑步、蹲下、跳躍、戰鬥或追逐。沒有必須越過的高差、爬行通道、同時壓住兩處的多人機關。必要道具放在站立可互動範圍。

### 3.2 初版人物參數

- 世界以公尺為單位，人物膠囊高1.75、半徑0.25，視點高1.6。
- 走路速度每秒1.6公尺；依經過時間計算，斜向量正規化。
- 水平360度、俯仰上下各80度，垂直視野預設65度，可調55～80度。
- 互動射線最遠1.8公尺，需碰到可見且有權限的互動目標；牆與關門必須遮擋。
- 門的碰撞淨寬至少0.9公尺，主要通道至少1.0公尺；不以模型外觀尺寸代替實際淨寬。
- 地板齊平或緩坡；活動門遇角色延後關閉或停止，不推擠玩家穿牆。
- 不強制鏡頭晃動；恐怖演出不搶轉視角，必要線索保留回看。

以上為製作起始值，待原型測試調整。調整尺寸、速度或視野時，記錄原因並重跑VERIFY的MOV、CAM、SPACE項目。

## 4. 空間路線與門禁

### 4.1 初次通關路線

序章櫃檯 → 電梯 → 四樓走廊 → 404客房 → 浴室 → 鏡後通道 → 監控室 → 檔案室 → 服務走道 → 終局櫃檯。

序章與終局櫃檯共享場景資產，但用不同劇情狀態顯示。電梯以固定車廂、門片和燈光表現移動，不真的升降人物。

### 4.2 回訪

機關開通後，404、浴室、鏡後通道、監控室、檔案室與服務走道保持可雙向行走，直到終局確認。終局缺印章可走服務走道回第五關，不必重新解前面的題目。

回訪的浴室門可以重新開啟；鏡後牆板與已解鎖門不重置。物品與筆記可隨時重讀。電梯不提供回序章的必要路線。

### 4.3 原型空間預算

| 區域 | 初版可用範圍 | 配置重點 |
|---|---|---|
| 櫃檯大廳 | 約6×5公尺 | 櫃檯前可走、員工站後方，終局出口與服務走道分開 |
| 電梯 | 約2.4×2.4公尺 | 正面門、側邊按鍵、後鏡；每個互動點都可接近 |
| 四樓走廊 | 約1.4公尺寬、6公尺長 | 只有404可入；其他門有明確封閉狀態 |
| 404客房 | 約5×4.5公尺 | 書桌、床、浴室口間留通道；變化物不生成腳下碰撞 |
| 浴室 | 約3.4×3.0公尺 | 能後退比對鏡面；門扇不封死洗手台與暗格 |
| 監控室 | 約4.5×3.5公尺 | 六螢幕集中可見，桌椅不堵控制盒 |
| 檔案室 | 約4.5×4公尺 | 檔案桌、抽屜、來源終端彼此可達 |
| 鏡後／服務走道 | 淨寬至少1公尺 | 雙向通行，轉角留人物膠囊迴轉空間 |

這些是原型預算，不宣稱已有測繪模型；正式尺寸以實走與碰撞驗收為準。各區透過可載入的連接走道銜接，關卡切換時保持入口朝向，不依賴尚未繪製的整棟旅館建築圖。

實作時先建立下列分工，資料名稱可依引擎調整，語意不可擅自改變：

### 存檔補充

在BRIEF的旗標之外，加入存檔格式版本、場景識別、安全出生點識別、合法站位／朝向、門禁及已演出事件。物件狀態由存檔重建，不序列化暫時的渲染物件或游標鎖定狀態。

存檔在機關完成、取物與安全轉場後寫入。若在面板或演出途中退出，載入最近完整檢查點，明確告知，不假裝恢復到未保存的半步驟。最終確認前另存退房前檢查點，結局圖鑑與本局資料分開。

## 6. 分階段製作

### P1：3D行走原型

依賴：已確認操作需求。

先用簡單幾何體搭建地面、牆、0.9公尺門、1公尺走道、家具與活動門，實作人物、視角、游標與失焦處理；使用獨立量測走道測試速度與碰撞。

產出：可執行的移動原型、版本記錄、人物參數與測試錄影。

放行：VERIFY的MOV-01～10與CAM-01～06通過。此階段未過，不投入全關卡精細美術。

### P2：3D互動與2D面板完整範例

依賴：P1。

製作「走近書桌→E開文件→移動停止→滑鼠閱讀→關閉→點擊繼續→原位探索」的完整範例，再加入物品、筆記、拖曳替代操作、提示、字幕、暫停及初版存讀檔。

產出：可操作的文件、排序、輸入框範例；統一操作模式與證據資料。

放行：UI-01～08通過；存讀基本物品不遺失；不發生邊解題邊走動或輸入文字移動角色。

### P3：第一關完整樣板

依賴：P2。

完成序章、電梯、機關01／02、鏡面影像、門禁、四樓走廊及404入口。建立場景載入與失敗重試，驗證恐怖演出不影響真實碰撞。

產出：可從首頁開始、走到404的連續樣板，以及電梯所需2D素材。

放行：SPACE-00／01、PZ-01／02與AV-03～05；錯誤按鍵、重複互動與存讀均可恢復。

### P4：第二、三關

依賴：P3及共用證據系統。

完成404、四房客歸檔、三種門外回應、可暫停倒數、雙枕頭、浴室動線、固定鏡面快照、五異常、7183疊影與鏡後通道。

產出：單人可由電梯連續遊玩至監控室；碎片A、B正確取得，角色與擬態分離。

放行：SPACE-02／03、PZ-03～06、STORY-06／08／09；三種回應皆可前進，活動門不夾人。

### P5：第四、五關

依賴：P4。

完成六台監控、2023事件排序、五組歷史擬態、D超前通道、碎片C、報告D、拼合核對、ROOM-404分析、印章抽屜與服務走道。

產出：玩家理解完整規則，具備前往終局所需的證據；印章可漏拿、可回取。

放行：SPACE-04／05、PZ-07～10、STORY-03～07；關錯通道可恢復、來源分析不誤登記。

### P6：終局、回訪與存檔

依賴：P5。

完成退房預覽、有效／無效輸入、印章撤銷、三種結局、終局前回檔案室、首頁變化、檢查點與重新調查。

產出：完整可通關的初版，所有結局可重玩。

放行：SPACE-06、PZ-11／12、SAVE-01～07、ROUTE-A～D；撤銷三項前置條件的8種組合均驗證。

### P7：美術、聲音與閱讀品質

依賴：P6完整流程；不提前改已驗證碰撞尺寸。

置換旅館材質與道具、完成2D劇情分鏡及文件、調整影像、字幕、聲音、亮度與降低刺激模式。鏡面與六螢幕採可控成本的影像方案，先確保可讀與敘事正確。

產出：完整風格版本、素材清單與來源／使用權紀錄。

放行：UI-06／07、AV-01／02／06／07；置換模型後重跑MOV-03～05及SPACE-00～06。

### P8：完整驗收與缺陷修正

依賴：P7。

在記錄的環境跑全部必要案例、四條完整路線與首次遊玩測試，記錄實際用時、卡關點與提示使用。阻擋性問題修復後重跑受影響項目；除非新問題影響全流程，不無理由重複全套。

產出：填寫完的VERIFY執行結果、證據清單、已知問題與可遊玩版本。

放行：所有P0及必要P1通過；若沒有足夠新玩家或硬體測試，明列未驗證的難度／效能範圍，不宣稱全面支援。

## 9. 需要詢問使用者的變更

本輪兩個主要問題已獲回答，沒有未回答、會阻擋文件交付的需求。

後續遇到以下情況，先提出具體問題與影響，暫停有疑慮的工作，不自行更改：

- 引入跑步、跳躍、蹲下、追逐、戰鬥或改成非第一人稱。
- 要把2D鏡面機關改為全即時3D，造成謎底、素材或效能範圍改變。
- 要更動1／2人規則、三結局、關卡順序或封鎖犯錯後的真結局。
- 需要新增多人、上線帳號或外部服務；手機橫向觸控已由使用者於本輪明確授權。
- 需要付費素材、商業服務、公開發布或其他未授權的外部操作。

引擎與套件尚未選定，不能在文件中宣稱版本已驗證。進入程式實作時先查當時專案與官方文件，再提出適合目前需求的具體方案；不以本計畫推定已取得發布或採購授權。
