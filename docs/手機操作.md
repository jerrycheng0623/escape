# 手機橫向遊玩

開啟 https://jerrycheng0623.github.io/escape/ 後，先將手機轉為橫向。若畫面沒有旋轉，請關閉手機的直向鎖定。

- 左下搖桿：按住並往前後左右拖曳，角色會朝目前面向的方向走路；放手就停止。推得越遠走得越快，上限與電腦版相同。
- 轉頭：在右側3D畫面滑動，左右轉身、上下抬頭低頭。可以一手移動、一手轉頭。
- 互動：先走近物件，把畫面中央的準星對準標示。出現互動提示後，輕點3D畫面或右下「互動」。滑動與長按不會被當成點擊互動。
- 下一步：點右上「下一步」查看現在任務、具體操作和完成後要去哪裡。「筆記」可以回看線索，「物品」確認已取得的東西。
- 解謎：照片、監控片段、報告都能先點一張，再點另一張交換，不必使用電腦拖放。文件和面板太長時可上下滑動；鏡面照片也有「對齊四角」按鈕。
- 暫停與旋轉：開面板會停走；直向時顯示旋轉提示並暫停。回橫向後，點「觸控繼續探索」再走。序幕可以暫停、翻頁、略過或重看。

這是單人第一人稱探索，沒有跑步、跳躍與蹲下。存檔保存在目前瀏覽器；同一網址、同一瀏覽器可從首頁繼續。
