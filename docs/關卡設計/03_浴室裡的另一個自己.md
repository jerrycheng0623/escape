# 第三關：浴室裡的另一個自己

[返回總企劃](../BRIEF.md)｜機關05～06｜單人｜目標8～10分鐘

## 1. 關卡任務與場景

玩家進入浴室，鏡子起霧。擦開鏡面後，找出五個不符合正常反射的細節，再使用林澄留下的遮臉照片取得監控室密碼。

場景包含洗手台、浴缸、壁鐘、毛巾架、浴室門與大鏡面。可切換「看實景」「看鏡面」並以雙欄模式比對；不要求玩家同時操控兩個畫面。

入場時現實浴室門開著；開始鏡面比對前，門因門弓器自行關上，玩家可見整個動作。比對畫面使用入場時留下的固定觀察快照，門的開關狀態清楚標記為「觀察快照」。完成比對後回到現況：門已關閉。如此避免結尾忽然宣稱現實門關著而未交代。

## 2. 機關05：鏡中的錯誤

### 故事理由

鏡面正在依照玩家視線校準房間與擬態。每指出一項異常，就替它修好一處不一致。

### 操作與答案

擦霧以拖曳或「擦拭鏡面」按鈕完成。進入比對模式後，玩家點擊鏡面中的異常熱區，再選擇相符的異常說明。

| 項目 | 實景觀察快照 | 鏡面 | 判定理由 |
|---|---|---|---|
| 門 | 入場時打開 | 關閉 | 開關狀態不同 |
| 毛巾 | 一條白毛巾 | 兩條白毛巾 | 數量不同 |
| 水龍頭 | 完全關閉 | 水持續滴落 | 動作不同 |
| 壁鐘 | 03:17 | 03:18 | 時間不同，鏡面數字另以可讀刻字呈現 |
| 浴缸 | 無人、無拖鞋 | 邊緣有一雙濕拖鞋 | 額外物件 |

正常左右翻轉不算異常，不使用「毛巾在左／右」這種可能只是普通反射的答案。五處全部可由畫面確認，不必依賴滴水聲。

每找對一處，鏡面該處短暫變正常；找完後五處又同時恢復異常。字句由鏡內浮出：「你終於看見我了。」

### 錯誤與提示

點錯只顯示「這與正常反射相符」，不扣命、不隨機尖叫。已完成的異常保留勾選，不重置。

三級提示：先看狀態和數量 → 注意門、毛巾、水、時間與浴缸 → 明列五項差異及點擊位置。

### 完成效果

設定機關05完成，鏡面下方暗格打開，取得「林澄的遮臉照片」及照片框。背面寫：「不要看她的臉。將黑框覆住臉，四角才會留下答案。」

這是明確操作線索，不能要求玩家猜「翻轉照片」或憑滑鼠巧合解鎖。

## 3. 機關06：鏡子的密碼

### 證據與介面

照片有可翻面的黑色遮罩與四個半數字符號。鏡面四角有互補筆畫與四個定位點。相片背面另畫出「水平翻轉 → 遮住臉 → 對齊四角」三步圖示。

玩家可按翻轉、拖曳與微調按鈕。接近定位點時吸附，不使用難以控制的像素精準度作為難度。

### 操作與固定答案

1. 水平翻轉照片，使四角定位標記方向一致。
2. 把黑框覆在鏡中人臉的位置。
3. 對齊四個定位點，讓半數字組合為完整數字。
4. 由左上、右上、左下、右下讀取：`7、1、8、3`。
5. 於鏡後露出的門禁盤輸入`7183`。

數字順序由照片框上的①②③④明確標示。密碼只用於本關監控室門禁，不與03:17混用。

### 錯誤、提示與取得物

照片方向錯時定位點不亮；有一角未對齊時顯示「尚未完整重疊」。密碼錯誤允許重試，不消耗照片。

三級提示：看照片背面三步圖 → 先水平翻轉再遮臉對角 → 依序讀取7183並輸入。

完成後門禁開啟，照片框夾層露出報告碎片B：「觀察擬態，不等同核定其身分。」自動取得，於第五關拼合。

### 因果與恐怖演出

設定機關06完成、取得門禁權限及碎片B。玩家的校準讓擬態能自行移動。

回到現況視角，現實浴室門仍關著，鏡中門卻慢慢打開，一個與玩家輪廓相同的人走入。玩家角色不動，影像也繼續移動。

短暫暗場後字幕顯示：「剛剛那個不是你的倒影。」恢復畫面，鏡後牆板已滑開，露出監控室通道。

暗場不超過兩秒；降低刺激模式以鏡面漸暗替代，線索不變。

## 4. 製作需求

- 實景與鏡面各五項可切換狀態，鏡面遵守正常透視與基本反射。
- 起霧遮罩、固定快照、異常熱區、遮臉照片、四角疊字與門禁盤。
- 自行移動的剪影動畫，不需要具體展示玩家臉部。
- 字幕、滴水、門弓器、牆板移動、低語與可調低的突發音效。

## 5. 驗收條件

- 五處異常均為真正不一致，左右反射不誤判。
- 門的開閉在鏡面比較與結尾演出之間有交代。
- 翻轉與定位均有明確線索；單靠滑鼠或按鈕都可完成。
- 碎片B必定取得；完成後再次閱讀照片不重播驚嚇或關閉通道。

## 6. 第一人稱3D動線與檢查

- 玩家實際走入浴室、靠近鏡面按E，才開啟2D固定快照比對與疊影面板；自由轉頭不改變五項答案。
- 門弓器的關門動作需檢查人物是否站在掃動範圍；有人時延後，無人時才關閉，並在開啟比對前保留可見演出。
- 浴室門關閉不代表永遠上鎖；離開2D面板後可開門返回404。已完成快照與碎片不重置。
- 機關05開暗格，06輸入7183才開鏡後牆板；牆板開啟與通道碰撞同步，後方淨寬至少1公尺。
- 鏡中人物可自行活動，現實玩家不被強制移動或搶轉鏡頭；錯過演出可在筆記重看必要片段。
- 機關06完成後鏡後通道保持雙向可走；詳見[SPACE-03與PZ-05／06](../VERIFY.md)。
