# 第五關：房間裡到底有幾個人？

[返回總企劃](../BRIEF.md)｜機關09～10｜單人｜目標8～10分鐘

## 1. 關卡任務與場景

玩家進入檔案室，拼合內部調查報告，區分對外結論與實際規則，再追查第二位房客的來源。本關是海龜湯的解答段，也提供真正結局所需的管理員印章與撤銷條款。

場景包含檔案桌、公開報告、內部附件底板、管理抽屜、房客來源終端與一面內窗。內窗能望見404床鋪，讓新增照片與雙枕頭保持可觀察。

## 2. 機關09：拼湊調查報告

### 證據取得

| 碎片 | 來源 | 關鍵內容 |
|---|---|---|
| A | 第二關照片盒，自動取得 | 異常透過影像設備形成擬態 |
| B | 第三關照片框，自動取得 | 觀察不等於正式核定 |
| C | 第四關列印單，自動取得 | 口頭清點建立候補，退房確認才正式核定 |
| D | 本關公開報告的撕頁夾層 | 撤銷房號與入住程序的管理條款 |

必要碎片不設隱藏點擊門檻。若玩家已略過閱讀，物品仍保存在證據欄。

公開報告寫著「未發現超自然現象／事件涉及錯誤身分辨識／實驗已終止」。附件註記「對外摘要不適用於現場處置」，表明這是當年的掩飾性結論，並非遊戲突然宣布全部幻覺。

### 操作與答案

四張碎片依頁眉編號01～04與接合線拼入底板；可旋轉與吸附，也可選片後點擊格位。正確排列即A、B、C、D。

拼圖本身不以難辨紙邊拖延閱讀，真正的推理在拼合後的三道核對題：

| 題目 | 正解 | 證據 |
|---|---|---|
| 看見另一個人是否等於放它出去？ | 否 | 碎片B |
| 哪個程序讓候補取得離館資格？ | 櫃檯退房確認 | 碎片C |
| 沒有有效房號時，入住能否成立？ | 否 | 碎片D |

### 拼合後完整規則

> 鏡中個體是房間的擬態，不會因被看見便自動取代人類。
> 它需要一份被正式確認的房客身分。
> 服務清點只能建立候補；退房核定才能讓候補隨人離館。
> 若房號來源無效，相關入住紀錄必須撤銷。
> 管理員得以「查無此房」印章終止無效房號的登記程序。

報告中的「不要數出多出來的那個人」是口語警示；上段才是操作定義。

### 錯誤、提示與完成效果

答錯時指出可回看的附件編號，不整份重置。三級提示：先分清觀察、候補與核定 → 閱讀C、D的程序詞 → 核對答案依序為否、櫃檯退房確認、否。

設定機關09完成、revocationEvidenceRead為真。附件底板下的管理抽屜解鎖，內有「查無此房」印章及使用說明：「於原始住宿頁蓋印，撤銷整筆異常入住；不可只在副本上操作。」玩家須主動拿取，尚未拿取時抽屜保持可見。

## 3. 機關10：最後的入住名單

### 單人版名單

終端只有兩列：

- 第一列：「調查者／1人／本人入住」。
- 第二列：「████／候補／來源待核對」。

不是四位玩家與第五名房客；所有對白稱「另一位」「第二份紀錄」。

### 推理證據

終端提供三份來源，不要求玩家憑感覺選「房間是鬼」：

1. 原始建築圖：四樓核准房號為401、402、403、405、406、407、408，404欄是未核准的設備夾層，標註「不可作客房」。
2. 本局候補資料：來源類別為「空間」，來源代碼`ROOM-404`；姓名欄只是顯示名稱，尚未核定。
3. 歷史事件對照：歷代人名與外貌不斷變換，第二份紀錄的來源代碼卻始終相同。

原始建築圖與第一關舊平面圖不同：第一關是後來使用中的客房配置圖，已被異常加入404；本關是核准原圖。兩份圖標明版本，讓差異能成為證據。

### 操作與答案

玩家將三份證據放入「房號合法性」「候補來源」「跨年份一致性」三格，再回答：

「第二份候補紀錄的來源是？」

選項：林澄、玩家本人、旅館員工、404號房。

正解：404號房。選擇後按鈕文字是「完成來源分析」，不是「確認入住」，避免推理動作被當成正式承認。

### 錯誤與提示

選人名時顯示「此姓名未與固定來源代碼吻合」，保留證據，可重選。三級提示：忽略每年的外貌，找固定欄位 → 比對ROOM-404與來源類別 → 第二份紀錄來自404號房本身。

### 完成效果與因果

設定機關10完成、registrationSourceResolved為真。候補資料顯示「來源分析完成／等待櫃檯核定」。房間利用玩家的調查整理出最後一份文件，但玩家也握有判定來源無效的證據。

此時住宿簿更新為「入住1／候補1／待核定」，不能顯示已正式入住2人。電話響起：「資料已齊，請回櫃檯辦理退房。」通往櫃檯的服務走道打開。

## 4. 轉場前的公平提醒

出口旁的管理交接板有三項可自行勾選的文字：「已讀處置條款」「已追查登記來源」「管理物品已取回」。缺少印章時，筆記提示「抽屜裡似乎還有東西」。

不強制拿取印章，也不直接說這是隱藏結局。玩家可選擇離開；第六關在最終核定前仍允許返回本關。

## 5. 製作需求

- 公開報告、A～D碎片、拼合底板、三題核對、抽屜與印章。
- 兩個版本的平面圖、候補來源資料、歷史固定代碼表。
- 終端狀態切換、內窗房間變化、服務走道。
- 印章為可選取物品，取得與未取得狀態分別儲存。

## 6. 驗收條件

- 四張必要碎片皆可取得，前關自動收取的證據不會遺失。
- 推理結論可由三份證據推出，非依劇作者突兀宣告。
- 完成來源分析不等於登記第二位房客。
- 門外曾回答「兩位」仍可透過撤銷取得真正結局。
- 真正結局條件明確，與無提示的全收集率無關。

## 7. 第一人稱3D動線與檢查

- 玩家走到檔案桌按E閱讀、拼報告及核對答案，再走至抽屜取印章、至來源終端分析；主要解題面板皆為2D。
- 09完成才解除抽屜互動限制；印章在站立可達的位置，按E拿取後才加入物品欄，不能只因抽屜解鎖就視為持有。
- 內窗僅供看見404的雙枕頭與床頭照，具有實體阻擋；隔窗不可射線取物。
- 10完成才打開服務走道；走道通往終局櫃檯，確認結局前始終允許雙向步行。
- 回訪不重播來源揭露、不重鎖抽屜；尚未拿取的印章持續可見可拿。往監控室的已開門同樣保留。
